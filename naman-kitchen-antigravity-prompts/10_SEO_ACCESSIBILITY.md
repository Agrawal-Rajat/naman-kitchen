# 10 — SEO, Accessibility & Semantic Quality

## SEO basics

Every route needs:
- unique title
- unique meta description
- semantic heading hierarchy
- canonical URL strategy when production domain is known
- meaningful image alt text
- Open Graph metadata
- favicon
- theme color

Suggested titles:

Home:
`Naman Kitchen | Modular Kitchens in Indore`

Kitchens:
`Modular Kitchen Designs | Naman Kitchen`

Hardware:
`Kitchen Hardware & Storage Solutions | Naman Kitchen`

Projects:
`Modular Kitchen Projects | Naman Kitchen`

About:
`About Naman Kitchen | Smart Kitchen Design & Craftsmanship`

Contact:
`Book a Kitchen Consultation | Naman Kitchen`

Do not keyword-stuff.

## Local relevance

Naturally mention:
- Indore
- Madhya Pradesh
- Indian homes
- modular kitchens

Do not create fake location pages for cities where the company has no verified operation.

## Accessibility

Requirements:
- semantic `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- buttons must be buttons
- links must be links
- form controls need labels
- keyboard navigation
- visible focus
- meaningful alt text
- decorative images `alt=""`
- accessible mobile menu
- ESC closes overlays
- focus management for modal/drawer
- reduced motion support

## Color contrast

Never sacrifice readability for visual luxury.

## Performance

- lazy-load below-fold images
- preload only the critical hero asset
- use modern image formats
- specify image width/height or aspect ratio
- avoid layout shifts
- avoid huge JavaScript bundles
- avoid unnecessary dependencies

## Core Web Vitals mindset

Optimize:
- LCP: hero image and hero typography
- CLS: reserved image dimensions
- INP: avoid expensive JS on interaction

## 404

Create a branded 404:
`Looks like this kitchen layout doesn't exist.`

CTA:
`Back to Kitchens`

This is a playful brand moment but must remain usable.

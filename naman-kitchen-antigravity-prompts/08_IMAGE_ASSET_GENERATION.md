# 08 — Image & Asset Generation Prompt Pack

## Objective

Create a consistent image library for Naman Kitchen.

Images should look like premium architectural photography, not obvious AI art.

## Global image direction

All generated kitchen images should prioritize:
- realistic Indian-modern homes
- premium but believable cabinetry
- warm daylight
- walnut / oak / beige / stone
- practical storage
- refined black or brushed metal hardware
- realistic appliances
- human-scale proportions
- clean architecture
- subtle plants and lifestyle objects
- no visible brand logos
- no text embedded in the image
- no distorted handles
- no impossible cabinetry
- no warped appliances
- no excessive decorative clutter

## Material board

Create separate images for:
- walnut wood grain
- light oak
- beige stone
- charcoal matte laminate
- brushed metal
- warm ivory laminate

Keep camera angle and lighting consistent so they work as a visual material system.

## Project gallery prompts

Generate 6–12 unique kitchens:
- compact apartment
- family kitchen
- luxury villa
- minimal monochrome
- warm wood
- modern Indian
- island kitchen
- small straight kitchen
- U-shaped kitchen
- L-shaped kitchen
- dark premium kitchen
- light airy kitchen

## Cutout assets

Generate isolated transparent PNG-style subjects where useful:
- cabinet handle
- drawer box
- pendant light
- spice jar set
- wooden cutting board
- brass bowl
- ceramic cup
- plant
- material swatches

These should be used sparingly as editorial foreground objects.

## Asset rules

Use WebP/AVIF for large web images when supported by the pipeline.
Use SVG for logos/icons where possible.
Use PNG only when transparency is genuinely needed.

Generate desktop and mobile hero crops separately rather than relying on one crop.
